Graphrt runs the AI assistants and automations your business depends on, on your own servers or the cloud you already use. Idle agents switch off and wake up in milliseconds, so customers get fast answers and you stop paying for servers that sit and wait.

- **Your data stays with you.** Run it on your own servers, AWS, Google Cloud, Azure or a local cloud. Nothing passes through us.
- **Pay for work, not for waiting.** Idle agents scale to zero and wake on demand.
- **Built by the people who run the process.** Business teams build agents in Graphrt Desktop with no code. Engineers install one small Rust binary.
- **Open source.** Apache 2.0, no lock in.

## Repositories

| Repository | What it is |
| --- | --- |
| [graphrt](https://github.com/Graphrt/graphrt) | The runtime. One small Rust binary that runs agents as a CLI, an HTTP service, a scale to zero gateway, or inside your app |
| [graphrt-builder-desktop](https://github.com/Graphrt/graphrt-builder-desktop) | Graphrt Desktop, the no code app for building and testing agents |
| [graphrt-plugins](https://github.com/Graphrt/graphrt-plugins) | Plugins for WhatsApp, Slack, Google Sheets, Gmail, databases and more |
| [graphrt-examples](https://github.com/Graphrt/graphrt-examples) | Example agents to copy and adapt |
| [homebrew-graphrt](https://github.com/Graphrt/homebrew-graphrt) | Homebrew tap |

## Get started

```sh
# Homebrew (macOS, Linux)
brew install graphrt/graphrt/graphrt

# or the install script (Linux, macOS)
curl -fsSL https://raw.githubusercontent.com/Graphrt/graphrt/main/install.sh | sh
```

Not technical? Download [Graphrt Desktop](https://github.com/Graphrt/graphrt-builder-desktop/releases/latest) and build your first agent without writing code.
